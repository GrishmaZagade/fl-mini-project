# Smart Washing Machine – Fuzzy Inference System

A Mamdani Fuzzy Inference System that optimizes wash cycle settings.

## Inputs
- Dirt level (0–100%)
- Fabric sturdiness (0–10)
- Load size (0–8 kg)

## Outputs
- Wash time (min)
- Water level (%)
- Spin speed (rpm)
- Detergent (ml)

## Details
- 27 fuzzy rules
- Min–max inference, centroid defuzzification
- Built with HTML5, CSS3 and JavaScript (ES6)
  
## How to run
Open `index.html` in any browser.
